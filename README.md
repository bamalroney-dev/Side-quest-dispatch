# Side Quest Dispatch

A Jekyll newsletter for Disney, Pokémon, gaming, Oklahoma events, concerts, and major news.

Published at https://bamalroney-dev.github.io/Side-quest-dispatch/ after enabling GitHub Pages in Settings → Pages (Deploy from branch: main, /(root)).

New issues belong in `_posts/YYYY-MM-DD-side-quest-dispatch.md`.

For local development, run `bundle install` then `bundle exec jekyll serve`.
